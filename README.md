# PINN для стационарного уравнения переноса с диффузией (DeepXDE) — проверено против точного решения

Физически информированная нейросеть (PINN) решает одномерное уравнение конвекции–диффузии — распределение концентрации примеси в трубе, где действуют перенос потоком и диффузия:

c″ − Pe·c′ = 0,  x ∈ [0, 1],  c(0) = 0,  c(1) = 1,  число Пекле Pe = 5.

Точное решение (выведено аналитически):

c(x) = (e^{Pe·x} − 1) / (e^{Pe} − 1).

## Метод (как в коде `pinn_advection_diffusion.py`)
- Библиотека DeepXDE (backend PyTorch).
- Сеть: 3 скрытых слоя по 32 нейрона, tanh, инициализация Glorot normal.
- Функция потерь = средний квадрат невязки r = c″ − Pe·c′ в 40 точках внутри отрезка + штрафы за граничные условия c(0) = 0 и c(1) = 1. Правильных ответов c в точках обучения сеть не получает — только уравнение и края.
- Производные c′ и c″ — автоматическим дифференцированием (`dde.grad.jacobian`, `dde.grad.hessian`).
- Обучение: Adam (lr = 10⁻³, 10 000 итераций), затем L-BFGS. Seed 0. В текущем запуске L-BFGS останавливается почти сразу (0.01 с) и результат не меняет — итог фактически даёт Adam; почему — ещё предстоит разобрать.
- Время обучения на CPU: ≈ 8 с.

## Проверка
Ответ сети сравнивается с точным решением на **1000 равномерных точках**, которых не было среди точек обучения:

relative L2 = ‖c_pred − c_exact‖ / ‖c_exact‖ = **2.26·10⁻⁴** (≈ 0,02 %), запуск 17.11.2026.

Лог обучения показывает три части функции потерь отдельно: [невязка уравнения, условие при x = 0, условие при x = 1]; к концу Adam: [2.2·10⁻⁵, 7·10⁻⁹, 9·10⁻⁹].

Маленькое значение функции потерь на точках обучения само по себе ничего не доказывает; поэтому точность меряется отдельно, против эталона.

## Ограничения (честно)
- Одна задача и одно значение Pe = 5. При больших Pe у правого края появляется тонкий пограничный слой — этот режим пока не проверен.
- Разброс результата по разным seed не оценивался.

## Следующие шаги
1. Pe = 20, 50: как меняется ошибка в пограничном слое; нужна ли концентрация точек у x = 1.
2. Сравнение с конечно-разностным решением той же задачи (точность и время).

## Запуск
```
pip install -r requirements.txt
DDE_BACKEND=pytorch python pinn_advection_diffusion.py
```
Программа печатает relative L2 против точного решения.
